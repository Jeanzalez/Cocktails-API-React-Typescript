# 🍹🔍 Buscador de Cócteles por Ingrediente

Aplicación web que permite consultar cócteles según un ingrediente específico utilizando las API'S de **[TheCocktailDB](https://www.thecocktaildb.com/)**. Los usuarios pueden ver la receta completa de cada cóctel, así como agregarlos o eliminarlos de su lista de favoritos. Desarrollado con **React**, **TypeScript**, y tecnologías modernas para una experiencia fluida y atractiva.

🔗 **[Ver Demo en Netlify](https://strong-crepe-a5586e.netlify.app/)**

## 🚀 Tecnologías utilizadas  
- React ⚛️  
- TypeScript 🟦  
- Tailwind CSS 🎨  
- React Router DOM 🌐  
- Axios 📡  
- Zustand 🧠  
- Zod ✅  

## 📌 Características  
✅ Buscar cócteles por ingrediente principal  
✅ Ver recetas detalladas (ingredientes, instrucciones, imagen)  
✅ Agregar o eliminar cócteles de favoritos  
✅ Validación de datos con Zod  
✅ Navegación fluida con React Router DOM  
✅ Estilos modernos y responsivos con Tailwind CSS

## 📂 Instalación y ejecución  
Si deseas probar el proyecto en tu entorno local, sigue estos pasos:  

1. Clona este repositorio
2. Entra en la carpeta del proyecto "bebidas-react-typescript"
3. Instala las dependencias:  
   npm install
4. Inicia el servidor de desarrollo:  
   npm run dev
